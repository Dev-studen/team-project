# ABR 시뮬레이터 검증 테스트 시나리오 초안

## 1. 네트워크 대역폭 급락 시나리오 (Drop)
* 목적: 대역폭이 갑자기 떨어질 때(예: 10Mbps -> 1Mbps) ABR 엔진이 비트레이트를 하향 조정하여 버퍼 끊김(Rebuffering)을 방지하는지 검증.

## 2. 네트워크 대역폭 급상승 시나리오 (Spike)
* 목적: 대역폭이 여유로워질 때 ABR 엔진이 비트레이트를 상향 조정하여 화질을 개선하는지 검증.

## 3. 패킷 손실률 증가 시나리오 (Loss)
* 목적: 대역폭은 유지되지만 패킷 손실률이 증가(예: 0% -> 15%)하여 유효 처리량이 감소할 때, 시스템이 이를 인지하고 화질을 낮추는지 검증.
